 Underwater Image Enhancement and Restoration System

About the Project
This is a Python-based project that improves the quality of underwater images. It corrects colours, removes haze, improves contrast, and makes images clearer.

Objectives
- Correct underwater image colours.
- Remove haze from images.
- Improve image contrast.
- Make images sharper and clearer.
- Check image quality using PSNR and SSIM.

Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-image
- Google Colab

 Features
- Upload underwater images.
- Colour correction.
- Dark Channel Prior.
- Haze removal.
- Contrast enhancement.
- Image sharpening.
- Image quality evaluation.
- Save and download the final image.

How It Works
1. Upload an underwater image.
2. Display the original image.
3. Correct image colours.
4. Calculate the dark channel.
5. Remove haze.
6. Improve contrast.
7. Sharpen the image.
8. Calculate PSNR and SSIM.
9. Display and save the final image.
